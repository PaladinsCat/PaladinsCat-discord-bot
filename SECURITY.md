# Security Policy

Please report suspected vulnerabilities through GitHub's private vulnerability
reporting form for the PaladinsCat project:

[Report a vulnerability privately](https://github.com/PaladinsCat/PaladinsCat/security/advisories/new)

Do not open a public issue or pull request containing vulnerability details,
credentials, personal data, or production information.

Include the affected component and version, reproduction steps, impact, and any
suggested mitigation. Use placeholder credentials and redact personal data.

This repository's scope is the PaladinsCat Discord bot.
